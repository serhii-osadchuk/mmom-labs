# Практичне заняття 3 (PN-Supervisor / ABM-Executors), варіант 17

**Автор:** Осадчук Сергій, аспірант 1 року навчання, Західноукраїнський національний університет.
Дисципліна «Математичне моделювання та обчислювальні методи».

Гібридна система: мережа Петрі (PN-Supervisor) видає дозволи на вхід у критичну зону,
мобільні роботи (AMR) рухаються автономно (ABM-Executors).

**Варіант 17:** 3 AMR, 3 верстати, 2-місний паралельний проїзд (K = 2), v_max = 1,1 м/с,
межі критичної зони [6,0; 15,0] м, час обробки 8,0 с.

## Файли

| Файл | Призначення |
|---|---|
| `original/pn_abm_original.py` | прототип викладача з PDF, перенесений без змін логіки |
| `pn_abm_variant17.py` | код для варіанта 17 (структура прототипу збережена) |
| `CHANGES.md` | **що виправлено в прототипі та що змінено для варіанта** |
| `results/changes.diff` | точний diff між прототипом і варіантом |
| `run_original_headless.py` | запуск оригіналу без вікна (кадр у `results/`) |
| `run_variant17_headless.py` | запуск варіанта без вікна: кадри, журнал переходів, перевірки |
| `test_pn_variant17.py` | автотест властивостей мережі Петрі |

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python pn_abm_variant17.py            # анімація у вікні (як у прототипі)
python run_variant17_headless.py      # журнал переходів + кадри results/snapshot_*.png
python -m unittest -v                 # автотест
```

Щоб отримати інший варіант, змінюються лише константи у секції «0. ПАРАМЕТРИ ВАРІАНТА»
(`N_AMR`, `N_MACHINES`, `CZ_CAPACITY`, `V_MAX`, `CZ_ENTRY_X`, `CZ_EXIT_X`, `T_PROC`).
